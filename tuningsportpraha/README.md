# Tuning Sport Praha — nový web

Jednostránkový web ve stejném formátu a vzhledu jako pepegarage.cz
(ocelová modrá + žlutá, výstražný pruh, písmo Archivo, bez build kroku).

Stačí nahrát obsah této složky na hosting (nebo do vlastního repozitáře na GitHub Pages).

## Fotky

Do `images/` nahrajte tyto soubory (JPG, do ~300 kB). Dokud tam nejsou,
ukazuje se místo nich šedé pole s názvem souboru:

- `hero.jpg` – velká fotka na pozadí úvodu (na šířku, 1920 px)
- `dilna.jpg` – dílna / majitel (na výšku 4:5)
- `emise.jpg`, `lesteni.jpg`, `diagnostika.jpg` – pás tří fotek u služeb (na výšku 3:4)
- `vjezd.jpg` – vjezd do servisu (na šířku 16:9)

## K ověření

Otevírací dobu mimo měření emisí (denně 7–16 h) jsem nenašel, proto je u ostatních
služeb „po telefonické domluvě“. Ceny jsou „od“ podle stávajícího webu.
